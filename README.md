# AI-Academy

Source for the **AI Engineering on Microsoft** learning program: a Beginner and an Advanced roadmap, plus self-paced course modules (in progress).

- `_source/` — roadmap content (and, later, course lessons)
- `_build/` — build and link-check scripts; see [`_build/README.md`](_build/README.md)
- `docs/` — topic trees and course design decisions

All scenario content uses the fictional company Contoso. Don't commit real organization names, tenant or account details, or credentials.
